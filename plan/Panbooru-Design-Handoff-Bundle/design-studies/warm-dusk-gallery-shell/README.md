# Warm dusk — gallery shell study

**Status:** provisional visual exploration · not approved tokens  
**Direction:** Candidate C from the 18 Oct 2026 visual brief  
**Scope:** foundations + gallery shell only (sidebar, search row, justified thumbs)

## Open

Open `index.html` in Firefox (primary). Assets symlink to `../../panbooru-ui/assets`.

## What this is

A static composition study to judge Warm dusk surfaces, type, corners and search/thumbnail treatment against the locked interaction model. Toggle **Docked / Floating search** and **Pending Search** in the study bar.

## What this is not

- Not a general visual reference until values are selected with the owner
- Not the interaction prototype (`panbooru-ui/`)
- Not production CSS for the Svelte app

All CSS custom properties under `:root` are labeled provisional in the study chrome.
